Furniwell SEO Roadmap

从关键词机会到页面落地的执行看板。当前重点：先建立页面建设施工标准，再按优先级推进核心品类页面。

1. Roadmap核心逻辑

竞品 / Keyword Gap发现机会 → 确定页面类型 → 建设页面 → 内链强化 → Ahrefs / GSC监控 → 持续迭代

施工原则：不是“为了SEO加文字”，而是让每个页面都有明确的搜索意图、关键词范围、内容结构和内部链接角色。

2. 页面建设施工标准

2.1 Collection 分类页

目标：承接核心品类词、商业调查型搜索和大量相关长尾词，是核心SEO入口。

模块建设标准Furniwell示例
Title核心词靠前，并自然加入购买/功能意图Höhenverstellbarer Schreibtisch elektrisch kaufen
H1明确品类主题，不使用泛标题Elektrisch höhenverstellbare Schreibtische
SEO Intro解释品类、核心卖点、适用人群，覆盖主要语义词高度调节、人体工学、Homeoffice等
产品列表展示可购买SKU，避免只有SEO文字没有交易承接Dual Ultra X / Economy Solid
筛选/细分尺寸、颜色、功能等维度承接细分需求140×70 / 180×80、白色等
购买指南解释如何选尺寸、功能、承重、使用场景如何选择升降桌尺寸
FAQ覆盖用户购买前的高频问题和长尾搜索稳定性、安装、承重、高度范围
内链向重点Product、Guide、Accessories传递主题关系Collection → Dual Ultra X → Kabelkanal
适用品类：升降桌、化妆桌、办公椅、厨房柜、凉亭、蹦床等有明确品类搜索需求的页面。

2.2 Product 产品页

目标：承接交易型关键词、型号词、规格词与产品功能长尾词，直接服务转化。

模块建设标准Furniwell示例
产品Title/H1产品名 + 核心品类词 + 关键属性Dual Ultra X Elektrisch Höhenverstellbarer Schreibtisch
首屏卖点快速回答“为什么买这个”三节立柱、70–80kg承重、Memory控制器
规格参数尺寸、材质、承重、高度范围等结构化呈现180×80 / 140×70
场景内容覆盖实际使用场景与场景词Homeoffice、Büro
功能解释把卖点写成用户可理解的决策信息高度记忆、稳定性、线缆管理
对比模块帮助用户比较不同型号或尺寸Dual Ultra X vs Economy Solid
FAQ解决安装、兼容、尺寸选择等障碍桌板尺寸、安装时间、承重
内链回链Collection，并链接Guide/配件Product → Collection / Guide / Kabelkanal

2.3 Guide / 内容页

目标：覆盖信息型搜索，扩大关键词覆盖，并把用户引导回商业页面。

模块建设标准升降桌案例
主题选择来自真实用户问题、Keyword Gap或竞品Top PagesWie wählt man einen höhenverstellbaren Schreibtisch?
开篇直接回答问题，避免长篇背景铺垫先说明尺寸、稳定性、高度范围的选择逻辑
主体内容分H2/H3覆盖完整子问题尺寸 / 承重 / 人体工学 / 使用场景
商业承接在合适位置推荐相关Collection/Product链接Dual Ultra X与升降桌Collection
FAQ补充问题词和长尾词Welche Größe ist ideal?

2.4 FAQ模块

目标：覆盖长尾问题、降低购买疑虑，并增强页面内容完整度。

用户问题搜索需求建议位置
Wie hoch sollte ein Schreibtisch sein?高度/人体工学Collection + Guide
Wie belastbar ist ein höhenverstellbarer Schreibtisch?承重/稳定性Product + Collection
Welche Schreibtischgröße ist fürs Homeoffice geeignet?尺寸/场景Guide + Collection

3. 页面上线前检查清单

☐ Title包含核心关键词且页面唯一
☐ H1与搜索意图一致
☐ URL简短、语义化、无无意义参数
☐ Meta Description有明确价值表达
☐ 正文覆盖购买决策信息
☐ 有真实规格与参数解释
☐ FAQ来自真实搜索问题
☐ Collection / Product / Guide之间有内链
☐ 图片文件名与ALT合理
☐ Canonical / Index状态正常
☐ 页面已进入Sitemap
☐ Product / FAQ等Schema按需要部署

5. 数据验证标准

页面建设完成后，不以“页面是否上线”作为结束，而以搜索表现是否增长作为验证。

监控指标用途
Organic Keywords判断关键词覆盖是否增加
Top 3 / Top 10判断核心词是否进入有效排名区间
Organic Traffic判断页面是否真正获得搜索流量
Traffic Value判断增长是否来自有商业价值的搜索
GSC Impressions / Clicks / CTR验证真实搜索曝光、点击与标题吸引力

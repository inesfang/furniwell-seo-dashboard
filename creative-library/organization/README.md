# 资源库导航与展示整理

2026-10-30，经用户确认，一级导航整理为：参考素材库、创意方案库、制作工作台、促销专题、产品与规范。

本模块只调整导航、列表和表单的展示方式。原始 DATA、需求数据、视频研究、促销数据、商品索引、产品结构、图片/视频 Prompt 编译器、导出函数和已有下载资料均保留。

## 内容归属

- 参考素材库：图片参考、视频样本、视频内容拆解。
- 创意方案库：Top 10 推荐视图、24 条原创方向、21 条独立需求建议、6 条视频方向。相近主题不合并记录；Top 10 与全部原创方向共用原 Creative_ID 和完整简报。
- 制作工作台：原图片与视频 Prompt 工作区。SKU、参考图、搭配椅、拍法、数量、版位和当前视频镜头保留原逻辑；已完成步骤可折叠为摘要。
- 促销专题：原黑五案例、研究结论、制作简报、排期与来源页。
- 产品与规范：原 6 款研究产品、需求研究中补充的 L 型/G2 核验，以及复用现有数据生成的结构、视频流程和投放规范。

原首页介绍、统计、核验范围、更新横幅和日期放入「资料范围与更新记录」。视频与促销研究概况、需求研究口径保留为可展开内容。产品未核实状态、来源类型与证据等级继续在相应列表/工作区展示。

## 链接兼容

继续使用现有地址参数，不迁移原记录：

- 图片参考：`#view=gallery`；制作工作台图片：`#view=gallery&ip=prompt`
- 视频参考：`#view=videos`；内容拆解：`&vt=analysis`
- 视频方向：`#view=videos&vt=directions`；制作工作台视频：`&vt=generator`
- 原 Top 10、全部方向、需求、促销与产品分别保留 `view=top10/plans/needs/promotions/products`。
- `material`、`creative`、`nd`、`vb`、`pc`、`pb` 等既有详情与筛选参数仍由原模块处理；SKU、搭配椅、图片数量与视觉参数仍由 Prompt 工作区处理。
- 产品规范新增 `#view=products&pr=rules`。

`view.js` 将原有节点移动到五个展示容器，保留原事件监听与状态。原模块调用 view/shareState 时刷新归属；同容器内不反复移除节点，以保持搜索和输入焦点。

## 验证

资料保留检查比较整理前后 DATA、研究对象、逐条需求简报、固定 Grok 制作包、促销 Markdown、视频 CSV 与两种中文 Prompt 制作包，确认内容一致。另检查主导航、全部子入口、完整简报、旧分享地址、四张图片任务与两个独立工作区。桌面与窄屏另以实际浏览器检查。

# Grok Imagine 最大字数核验

核验日期：2026-11-02。目标入口为 **grok.com/imagine 网页版**。

本次未查到 xAI 官方针对网页版 Imagine 所有账号、模式通用的最大字符数。本站没有把第三方 API 的输入限制写成 Grok 官网的统一限制。

## 来源与适用范围

| 来源 | 核验内容 | 本站使用方式 |
| --- | --- | --- |
| [Grok 官网 Imagine](https://grok.com/imagine) | 公开界面切到视频模式，输入框未显示明确最大字数，未读到 maxlength 属性。 | 记录所观察的网页状态，不据此推断后端无限制。 |
| [xAI 官方 Imagine 页面](https://x.ai/api/imagine) | 官方说明输入约束因端点而异，并可能更新。 | 不改写为网页版固定数字。 |
| [xAI 官方视频生成说明](https://docs.x.ai/developers/model-capabilities/video/generation) | 说明首帧、参考图、视频长度等生成方式，本次未找到网页版统一字符上限。 | 使用独立镜头与实际上传首帧的短指令。 |
| [xAI 官方视频接口字段](https://docs.x.ai/developers/rest-api-reference/inference/videos) | prompt 为文本字段，本次未找到可直接作为网页限额引用的字符数。 | 保留来源与核验日期。 |
| [Layer 自身的 Grok Imagine Video API 文档](https://layer.ai/docs/models/xai-grok-imagine-video) | 该接入入口的请求字段列出最多 4096 characters。 | 仅说明不同入口有各自限制，不将它标为 Grok 官网限制。 |

网页检查时，在官网未登录的公开视频模式，用无敏感内容的 5001 个中文字查看编辑框行为。当时保留了输入，未出现明确字数错误，检查后已清空。**没有提交生成、上传商品、消费额度或测试服务端是否接受该长度。**不能由此宣称真正生成上限大于 5000、无限制，或全部账号相同。

## 写入工作台的规则

- Grok Imagine 制作：默认每条最多 **900 字符**，这是团队的保守工作上限，**不是官方统一上限**。执行者可按当前界面明确提示调整。
- 本站表单接受 100–10000 的整数。这个配置范围属于本站表单规则，不是 Grok 产品规格。
- 每条实时显示「当前字符数／本次最大字数」，包含 SKU、空格、标点与换行，采用保守 UTF-16 长度。
- 超限、空白、无效上限或非独立任务时，禁止复制。下载短指令包时逐条检查，有一条不通过就阻止下载。
- 不机械截断商品结构、指定搭配椅或动作约束。文本过长时提示精简补充事实、按实际入口调整上限，或使用 Work 完整版。
- ChatGPT Work 制作：保留完整商品来源、结构事实、场景和验收任务，不套用 Imagine 的短指令工作上限。关键帧逐张实际交付；是否能直接产出视频取决于当前工具，不把文字当作视频成品。

未来如 xAI 公布可引用的网页版数字，或执行者的界面明确显示上限，应同时更新来源、适用模式和核验日期。

# Grok Imagine 与 ChatGPT Work 制作入口

2026-11-02，在升降桌图片、升降桌视频、猫砂盆制作台新增工具选择。

**ChatGPT Work** 使用完整制作简报和独立关键帧任务，不套用 Grok 短指令上限。**Grok Imagine** 使用独立图片／关键帧／视频短指令，显示本次最大字数，并在复制和下载时校验。

原始研究、SKU、原编译器和原导出函数保留不变。`targets.js` 从结构化结果派生不同工具的执行版本，`view.js` 负责界面选择、状态恢复以及工具对应的复制与下载。

默认保留原方式：升降桌完整制作包归 Work，猫砂盆原短指令归 Grok。桌椅图片按勾选风格生成，每种风格提供一条独立 Work 指令和对应 Grok 短指令。Grok 视频只选独立首帧或镜头；剪辑计划和完整资料通过 Work 查看。

字数核验见 [研究记录](limits-2026-11-02.md)。默认 900 是本站工作上限，可按当前界面实际提示调整，没有将第三方 4096 标为官网通用限制。

工具参数分别保存：升降桌使用 `ptool=work/grok` 和 `pmaxchars`；猫砂盆使用 `ktool=work/grok` 并复用 `kmax`。旧链接不带新参数时继续按原默认打开。

复制和导出按当前工具执行，防止原长包在 Grok 模式绕过长度校验。切换工具不会覆盖原编译结果；Work 编辑内容与 Grok 短版分开保存。

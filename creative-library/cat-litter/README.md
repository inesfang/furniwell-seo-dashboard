## 入口

左侧先选择「升降桌 / 桌椅」或「猫砂盆」。前者保留原有五个功能入口与全部研究、Prompt 生成器、分享链接和导出。

猫砂盆有五个入口：

- 视频参考与拆解：5 个完整上传视频的压缩预览、逐段时间线、画面观察、口播中文概述、表达优缺点和迁移边界。
- 视频素材思路：8 个衍生方向，明确来源片段、适用能力、开场、测试假设和不可移植内容。
- 视频制作工作台：选 SKU／商品链接、思路、视觉、画幅与字符上限，输出 5 张独立关键帧的中文 Prompt、5 条单镜头视频 Prompt 和 15 秒总览。
- 制作流程与规范：参考图、关键帧、Imagine 上传、剪辑、验收及广告表达要求。
- 产品与 SKU：13 款猫砂盆、16 个真实 SKU／颜色变体；另记录 3 项站内非猫砂盆商品，不套用猫砂盆流程。

新分享地址使用 `#view=cats&ct=samples/ideas/generator/workflow/products`。SKU、思路、视觉、比例、上限与镜头时长可恢复；原图确认不会通过分享链接自动勾选。原有 `view=gallery/videos/needs/top10/plans/promotions/products` 等地址不变。

## 五条视频与分析方法

来源是用户上传的五个文件。原始 TikTok 帖子、账号验证、播放与成交数据未提供，因此不标记为高流量或高转化样本。Paolillo 三条分别拆解，但属于同一组人物与家庭场景。

原文件总时长约 239.6 秒，均为 576×1024、约 30 fps，含音轨。记录原文件名、时长和 SHA-256。网页预览是完整内容的 H.264/AAC 压缩副本，未用生成图替换观察画面。

通过带时间的抽帧核对场景与转场，意大利语口播采用本地自动转写并对照可见字幕整理中文概述；不是逐字人工校订字幕。Sally 没有可用的口播内容，已排除自动转写幻觉，只分析画面。时间线为约数。

页面区分「画面观察」「口播概述」「制作推导／测试假设」，没有从这些片段认定同款 SKU 或安全认证。商品功能只依据对应官方变体与本次公开资料快照。

## SKU 与事实边界

`catalog.json` / `catalog.js` 是同一次官方公开商品数据快照（2026-11-02），包括 SKU、variant、原图、在售快照、结构摘要与来源。颜色以官方变体绑定图为准，不从 SKU 后缀推断。没有默认写入价格、折扣、认证或跨机型容量承诺。

自动款、App 款、手动不锈钢款分别做能力匹配。未知输入或有多个变体的链接必须先明确 SKU，不能沿用前一次选择静默生成。未在正文核实的 App 功能不启用。未逐 SKU 核实的机械运动方向与时长不生成，默认用空舱、静止的清洁后状态；真实动态清洁留给实拍／已核实素材。

## 关键帧与 Imagine

1. 实际保存并上传所选变体官方原图，编号 image1。
2. 生成并验收第一张关键帧 image2。每个任务只交付一张完整图片，不拼图。
3. 后续 image3–image6 使用 image1 锁商品，image2 锁房间、光线与已有角色；不要把生成结果当作商品结构依据。
4. Imagine 单首帧模式每次上传对应关键帧，再粘贴该镜头短 Prompt。文件编号和 @image 标签不会自动上传附件；多参考功能以实际界面支持为准。
5. 默认生成每镜 6 秒，剪取稳定连续的 3 秒，拼成 15 秒成片；界面支持 3 秒时可选择 3 秒。
6. 原图、关键帧、最终视频逐级验收产品与动作。真实 App 界面、KuzmoTec 品牌、标题与 CTA 后期加入。

## 长度校验

官方公开资料未列出 Grok 网页版 Imagine 统一字符上限，不能把 API 或第三方平台的限制冒充网页版限制。

默认 900 字符是保守工作上限。执行者可填写当前输入框显示的实际上限（100–10000）。空格、换行、标点均计数，使用保守的 UTF-16 长度。单条 Prompt 可编辑；超限或上限无效会禁用复制，不自动裁掉商品或动作约束。

目前所有 2,808 个有效 SKU／思路／视觉／画幅／时长组合中的单镜头视频 Prompt 均不超过 390 字符，关键帧不超过 523，15 秒总览不超过 691（用户编辑后需重新校验）。

下载的 Markdown 是分步制作包，包含多个独立任务，不受「单条」长度约束，也不应整体粘贴进 Imagine。页面不调用生成 API，不会自动产出图片或视频。没有声称已在用户的 Grok 账号完成生成测试。

## 验收

猫在内部或靠近时机构静止；清洁镜头需确认空舱且猫与人已离开活动区。人手与猫咪镜头分开，固定数量、一次一个动作，不生成把手伸进机构的测试。手动款不添加自动清洁或 App。保持产品的盖体、入口、踏板、按钮、底座与颜色不变。

广告不采用惊悚排泄特写、无依据效果保证、伪造红人推荐或健康诊断。实际产品、声明、活动与落地页保持一致，最终画幅、清晰度、安全区与披露按当前平台预览和要求复核。素材形式不等于审核保证。

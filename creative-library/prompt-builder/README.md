# 中文广告素材 Prompt 生成区

入口位于「视觉图片库 → 生成 Prompt」与「视频素材 → 生成 Prompt」。原有图片方向和视频方向卡片也提供「用此思路生成中文 Prompt」快捷入口。

## 执行流程

1. 输入完整 SKU，或德国站 / 法国站的具体商品链接，点击「识别商品」。不根据相似 SKU 猜测产品。
2. 商品链接存在多个变体时，先选择准确的颜色与尺寸。指定 `?variant=` 的链接只匹配该商品下的变体。
3. 核对官网产品原图。没有变体绑定图时，必须选择原图并确认与当前变体一致。
4. 选择素材库已有思路、投放平台与市场。不适用于所选商品的结构方向会禁用。
5. 点击「生成中文 Prompt」，切换版位，复制或下载全部制作包。先保存官网原图，并实际上传到图片 / 视频生成工具，文字链接不会自动成为图片附件。

图片入口包括 24 条原创图片方向、7 条促销简报、21 条需求建议。视频入口包括 6 条 Shorts 方向、1 条促销简报、21 条需求建议。需求、场景与构图方法可迁移；旧 SKU、旧尺寸、颜色、配件和活动权益不作为当前商品事实。

输出的执行说明为中文，商品名称、原始 SKU、变体选项和来源链接保留官网原文。市场选择用于指定后期广告文案的语言。视频输出为 15 秒、5 个镜头，每个镜头包含独立首帧提示词和 3 秒图生视频提示词。搭配椅出现时，`@image1` 为主商品原图，`@image2` 为所选椅子原图，`@image3` 为当前独立镜头实际制作并验收的首帧。主商品本身是椅子时不额外添加搭配椅，此时仅用 `@image1` 主椅原图和 `@image2` 当前镜头首帧。

## 视频人物交互修订（2026-10-29）

默认从镜头 1 的静止首帧开始；每镜头分别选择「制作并验收首帧」与「仅 3 秒图生视频」，复制按钮明确标示当前步骤。15 秒总指令改为剪辑计划，完整制作包属于归档资料，不把全部分镜与首帧指令混作一个连续的视频生成任务。

`videos/interaction.js` 同时供中文生成器与六个固定 Grok 简报使用。每镜头分别定义出镜类型、相机、静止起点、唯一动作与终点：人物已坐稳，椅背在身后、骨盆由坐垫承托、双手分放左右大腿；手部特写仅一只右手与连续手腕前臂；升降镜头完全无人、固定相机且椅子在运动路径外。未知立柱结构不做机械运动。入座、起身、转身、伸手与升降不再串成连续动作；写字和擦拭保留原握持关系，只做短距离局部动作。裸桌架与未核实功能改为无人细节，不虚构按键或随货桌板。

首帧只画起始静止姿态，不混入动作与结束状态。先检查人数、手数、肩肘腕连接、椅背朝向、桌沿和扶手间隙；身体或商品错误的首帧先重做。每段使用本镜头已验收首帧，最终硬切剪辑；空镜不残留上一镜头的裤腿或手脚。验收视频开头、动作中间与结尾，失败则减少动作或保留已验收静帧。网页没有调用 Grok，也不声称已验证其实际生成的每一帧。

## 搭配椅

图片、视频两个生成区均提供指定的 Furniwell 高背人体工学办公椅与带按摩腰枕、脚托的电竞椅，可分别选择款式和颜色。默认灰色高背椅 G-OCNC23-0240-2。每个颜色独立绑定官网变体、SKU、主图；暂不可售或缺少对应主图的变体不用于默认生成，不能拿其他颜色图片替代。初始目录核对于 2026-10-29；切换款式或点击「核对官网状态」会读取当前官网，失败时明确使用有日期的核对记录。

选择椅子后，图片、总视频指令、每镜头首帧及每镜头图生视频均包含椅子 SKU、颜色、原图和结构约束；复制与下载使用同一选择。改变椅子款式或颜色会清除旧结果，分享链接可保留所选椅子。图片和视频各自保留选择。主商品本身是椅子时，隐藏搭配选项，不额外复制另一把椅子。

椅子独立于桌架，不随升降桌移动。保留原头枕、背靠、腰靠、扶手、坐垫、脚托、底座与脚轮，不能因场景透视改款。电竞椅官网图中的橙色按摩示意不是真实灯光，不能复制为发光腰枕或治疗效果。脚托不根据不清楚的图片臆造收折动画。搭配椅单独销售，不自动声称桌椅套装、赠品或组合优惠。

原有六个固定 Grok 视频简报统一使用灰色高背椅，附件顺序同步改为 image1 桌子、image2 椅子、image3 本镜头首帧；可从固定简报跳转中文生成区更换搭配椅。

## 四张图片批量执行

「本次图片数量」选择 4 张时，输出区默认提供当前统一版位的四张批量生成总指令，明确要求任务 1–4 全部完成并逐张输出四个独立图片文件。总指令只包含一个比例；产品、椅子和投放要求共用，四个拍法分别列出，不混入单张提示词的「只输出一张」总要求。

右侧版位选择只列版位，不再把 4 个拍法 × 4 个比例混成 16 个默认复制选项。「复制范围」默认完整批量，也可选择单张；四个任务卡可直接复制第 1–4 张 Prompt。「下载本组 4 张指令」导出当前版位的完整任务；「全部版位制作包」按版位分组，属于其他比例的备选指令。

网页生成制作指令，不直接调用图片生成 API。支持连续多图的生成工具可执行整批总指令；单次只能生成一图的工具须按四个独立任务依次执行。不能把一张拼图、仅一张成图或四段文字当作完成四张交付。图片数量改为 1 时恢复单张任务。产品、搭配椅和拍法约束在两种模式中保持一致。

## 同一 SKU 的视觉差异

图片入口新增 8 种拍法：门口空间全景、正面深色背景、人物纪实、功能近景、夜间局部照明、干净棚拍、高位桌面任务、办公纵深。每种明确规定镜头、机位高度、光向、摆放关系、装修、道具、人物和排除元素。不同思路默认推荐不同拍法；可手动选择，或一次生成 4 套不同视觉方案，每套再分别输出所选广告版位。

自动模式按 SKU / 变体记录本浏览器近期使用的拍法，避开最近 3 种。只记录拍法编号，不上传生成图片，也不声称已对实际成图查重。手动指定允许复用。分享链接可保留手动拍法与方案数量；生成结果和本地历史不写进链接。

参考图只用于复制主 SKU 的商品结构，不继承参考图的房间、光线、椅子和摆件。优先使用清楚展示商品的白底图或产品实拍图；不同方案各自从产品原图开始，不能把上一张 AI 广告图当作下一张的产品结构依据。完整空间思路不使用棚拍或局部特写代替，裸桌架不生成桌面任务俯拍。功能近景可裁去无关部位，目标部件和所属安装边必须保留。

视觉变化不包括改变商品控制器、按键、拼缝、立柱、脚型或颜色。验收时分别核对产品一致性与拍法执行情况；只换杯子、盆栽或文案不算形成独立视觉。

## 商品一致性

本模块优先读取官网公开商品接口。SKU 检索使用德国、法国共 112 个商品 / 1,132 个变体的 2026-10-28 索引，再读取所匹配商品的最新变体；接口暂不可用时明确显示目录快照。新商品尚未进入 SKU 索引时，可直接使用商品链接。一个 SKU 对应多个变体时需要显式选择。

已核实 SKU 复用产品结构记录：入座者右手侧控制器、具体控制器形式、桌板拼缝、倒装立柱和原脚型。G2 不替换成 Economy 的外挂控制器；L 型保持原朝向和三个支撑。未逐项核实的商品使用原图约束，默认不模拟未知伸缩结构。补充事实由执行者对照原图、说明书或实物核实。

更换输入、变体、参考图、思路、平台、市场或补充信息会清除旧结果，避免复制过期产品 Prompt。图片和视频区保留各自的操作状态。分享链接可保留产品、思路、平台和市场，补充结构、活动和生成结果不会写入链接。

## 广告制作规则

Google 图片提供 1.91:1 与 1:1；Google 视频提供 9:16 与 16:9。Facebook 图片与视频提供 Feed 4:5、Reels / Stories 9:16。每个版位独立构图，不拉伸或机械裁切同一画面。具体像素、导出目标和安全区要求写入各版位 Prompt。

默认为无叠字图片 / 无字幕视频，品牌、广告文案和 CTA 在后期排版。这是制作默认值；并非平台全面禁止文字，也不套用已经过时的 Meta 20% 文字规则。未填写并确认的活动不使用历史优惠。禁止虚假证言、医疗效果保证、针对观众个人属性的暗示、伪造认证或界面按钮。图片、音乐、人物、声线必须有商业使用权限。

投放前仍须核对实际生成结果的结构、比例、编码、文件体积、适用 AI 标识、落地页与活动权益，并在广告后台预览各版位。生成 Prompt 不等于素材已通过平台审核。

规则版本与官方来源见页面「查看投放规则与来源」，以及 `engine.js` 中的 `sources`。本模块在浏览器中按产品和思路组合提示词，不调用模型服务，不需要输入模型 API 密钥，也不自动生成图片或视频。

## 文件

- `chairs.js`：指定搭配椅目录、变体与参考图绑定、独立结构约束及附件映射。
- `visuals.js`：拍法定义、思路适用性、近期拍法避让与具体视觉指令。
- `engine.js`：产品解析、适用性检查、中文 Prompt 与逐镜头制作包。
- `view.js`：两个独立操作区、公开商品读取、复制、下载与分享状态。
- `styles.css`：桌面与手机布局。
- `catalog.json`：官网公开商品索引，不包含结算价格或私人账户信息。

现有入口位于上一级 `index.html` 与 `videos/view.js`，既有素材和固定 Grok 简报继续保留。

# 中文广告素材 Prompt 生成区

入口位于「视觉图片库 → 生成 Prompt」与「视频素材 → 生成 Prompt」。原有图片方向和视频方向卡片也提供「用此思路生成中文 Prompt」快捷入口。

## 执行流程

1. 输入完整 SKU，或德国站 / 法国站的具体商品链接，点击「识别商品」。不根据相似 SKU 猜测产品。
2. 商品链接存在多个变体时，先选择准确的颜色与尺寸。指定 `?variant=` 的链接只匹配该商品下的变体。
3. 核对官网产品原图。没有变体绑定图时，必须选择原图并确认与当前变体一致。
4. 选择素材库已有思路、投放平台与市场。不适用于所选商品的结构方向会禁用。
5. 点击「生成中文 Prompt」，切换版位，复制或下载全部制作包。先保存官网原图，并实际上传到图片 / 视频生成工具，文字链接不会自动成为图片附件。

图片入口包括 24 条原创图片方向、7 条促销简报、21 条需求建议。视频入口包括 6 条 Shorts 方向、1 条促销简报、21 条需求建议。需求、场景与构图方法可迁移；旧 SKU、旧尺寸、颜色、配件和活动权益不作为当前商品事实。

输出的执行说明为中文，商品名称、原始 SKU、变体选项和来源链接保留官网原文。市场选择用于指定后期广告文案的语言。视频输出为 15 秒、5 个镜头，每个镜头包含独立首帧提示词和 3 秒图生视频提示词。`@image1` 是实际上传的官网原图，`@image2` 是该镜头实际制作并验收的首帧。

## 商品一致性

本模块优先读取官网公开商品接口。SKU 检索使用德国、法国共 112 个商品 / 1,132 个变体的 2026-10-28 索引，再读取所匹配商品的最新变体；接口暂不可用时明确显示目录快照。新商品尚未进入 SKU 索引时，可直接使用商品链接。一个 SKU 对应多个变体时需要显式选择。

已核实 SKU 复用产品结构记录：入座者右手侧控制器、具体控制器形式、桌板拼缝、倒装立柱和原脚型。G2 不替换成 Economy 的外挂控制器；L 型保持原朝向和三个支撑。未逐项核实的商品使用原图约束，默认不模拟未知伸缩结构。补充事实由执行者对照原图、说明书或实物核实。

更换输入、变体、参考图、思路、平台、市场或补充信息会清除旧结果，避免复制过期产品 Prompt。图片和视频区保留各自的操作状态。分享链接可保留产品、思路、平台和市场，补充结构、活动和生成结果不会写入链接。

## 广告制作规则

Google 图片提供 1.91:1 与 1:1；Google 视频提供 9:16 与 16:9。Facebook 图片与视频提供 Feed 4:5、Reels / Stories 9:16。每个版位独立构图，不拉伸或机械裁切同一画面。具体像素、导出目标和安全区要求写入各版位 Prompt。

默认为无叠字图片 / 无字幕视频，品牌、广告文案和 CTA 在后期排版。这是制作默认值；并非平台全面禁止文字，也不套用已经过时的 Meta 20% 文字规则。未填写并确认的活动不使用历史优惠。禁止虚假证言、医疗效果保证、针对观众个人属性的暗示、伪造认证或界面按钮。图片、音乐、人物、声线必须有商业使用权限。

投放前仍须核对实际生成结果的结构、比例、编码、文件体积、适用 AI 标识、落地页与活动权益，并在广告后台预览各版位。生成 Prompt 不等于素材已通过平台审核。

规则版本与官方来源见页面「查看投放规则与来源」，以及 `engine.js` 中的 `sources`。本模块在浏览器中按产品和思路组合提示词，不调用模型服务，不需要输入模型 API 密钥，也不自动生成图片或视频。

## 文件

- `engine.js`：产品解析、适用性检查、中文 Prompt 与逐镜头制作包。
- `view.js`：两个独立操作区、公开商品读取、复制、下载与分享状态。
- `styles.css`：桌面与手机布局。
- `catalog.json`：官网公开商品索引，不包含结算价格或私人账户信息。

现有入口位于上一级 `index.html` 与 `videos/view.js`，既有素材和固定 Grok 简报继续保留。

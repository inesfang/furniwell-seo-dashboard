# 视频素材板块

公开路径：`creative-library/#view=videos`。沿用原站导航、分享参数与详情对话框。

本次加入 2026-10-27 的 YouTube Shorts 研究：18 条公开样本、7 条字幕信息拆解（含 1 条低播放对照）、6 份 Furniwell 原创 15 秒分镜。

- `data.js`：公开研究快照。保存整数播放量、核验日期、发布时间、原片链接、语言/主题范围与证据状态；不包含原始完整字幕或内部广告账户数据。
- `view.js`：样本搜索、范围/证据筛选、播放量/日期排序、按需播放器、字幕段落、原创分镜、复制/下载与 CSV 导出。
- `styles.css`：仅新增视频板块样式，与原图片、需求和促销板块保持兼容。
- `research-2026-10-27.md`：完整研究与来源，可直接下载。

## 分享

- 视频样本：`#view=videos`
- 制作方向：`#view=videos&vt=directions`
- 内容拆解：`#view=videos&vt=analysis`
- 指定简报：`#view=videos&vt=directions&vb=FV-01`
- 指定原片：`#view=videos&vs=SOQWyzsacQg`

搜索和筛选也随“复制当前分享链接”保留。原视频按需使用 YouTube 隐私增强播放器，并始终提供原站外链。公开缩略图加载失败时显示标题封面与可用入口，不显示破图。

## 后续更新约束

1. 新数据明确记录核验日期；未重新核验时不更新日期或声称是实时数据。
2. `visual_reviewed` 本次全部为 false。不能把字幕段落称作视觉切镜，也不能按标题补写动作。
3. 英语参考、L 型桌和走步机邻近主题保持可见分类；低播放对照不包装成高播放成功案例。
4. 视频原片拆解与 Furniwell 原创分镜分开；性能、配件与价格对应实际产品。
5. 公共累计播放不代表付费流量、德国受众、完整观看或成交。无竞品 CTR/ROAS 不补值、不评分。
6. 促销尾卡是当日快照，使用前重新核对；保留无促销版。

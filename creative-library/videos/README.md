## Grok 产品一致性

使用者正常入座、面对桌面时，控制器在其右手侧。前边是靠人的工作长边，不是相机画面的固定左右。两节倒装柱用“粗外套管在上、细内管在下并连接底脚”描述，升起时桌面和粗上套管一起上移，露出更多细下管，底脚保持原位。

默认 SKU：FV-01/03/05/06 使用白色四拼 Economy 120×60（44533451587850）；FV-02 使用黑色 L 型 160×140×60（45028720378122）；FV-04 使用白色 G2 玻璃 140×70（45781441347850）。G2 为前沿右侧内嵌控制面板，禁止套用 Economy 外挂控制器。L 型主图为收合状态，不猜伸缩节数，本版不生成其伸缩过程。

推荐每镜头独立生成：主商品原图为 image1，指定灰色高背办公椅原图为 image2，实际制作并验收的本镜头首帧为 image3。提示词中的编号是需要上传的附件角色，不代表本页已经生成了首帧。只复制商品 URL 不能替代上传图片。Grok 若不解析文字中的 @image 标签，需在其界面手动指定附件。

提示词不保证生成模型每帧正确；必须对比产品原图、首帧、中间帧及尾帧，错款画面不得进入投放。

## 分享

- 视频样本：`#view=videos`
- 制作方向：`#view=videos&vt=directions`
- 内容拆解：`#view=videos&vt=analysis`
- 指定简报：`#view=videos&vt=directions&vb=FV-01`
- 指定原片：`#view=videos&vs=SOQWyzsacQg`

搜索和筛选也随“复制当前分享链接”保留。原视频按需使用 YouTube 隐私增强播放器，并始终提供原站外链。公开缩略图加载失败时显示标题封面与可用入口，不显示破图。

## 后续更新约束

1. 新数据明确记录核验日期；未重新核验时不更新日期或声称是实时数据。
2. `visual_reviewed` 本次全部为 false。不能把字幕段落称作视觉切镜，也不能按标题补写动作。
3. 英语参考、L 型桌和走步机邻近主题保持可见分类；低播放对照不包装成高播放成功案例。
4. 视频原片拆解与 Furniwell 原创分镜分开；性能、配件与价格对应实际产品。
5. 公共累计播放不代表付费流量、德国受众、完整观看或成交。无竞品 CTR/ROAS 不补值、不评分。
6. 促销尾卡是当日快照，使用前重新核对；保留无促销版。

# Furniwell 促销素材知识库 · Black Friday 2026

更新：2026-10-20。入口：../#view=promotions

这份研究以2023–2025黑五案例为主，补充2026已公开预热与当前页面，以及2019长期表达对照。德国Furniwell是应用对象；不同市场独立标注。研究不是全网穷尽，也没有竞品点击、购买或ROAS数据。

## 文件与复用

- `research-data.json` 是结构化事实与建议源，含案例、来源、年份证据、图片角色、产品事实与8份制作简报。
- `data.js` 是相同数据的页面载入版，更新时应保持两者一致。
- `references/` 是已检查的静态研究预览。所有路径本地化，GIF仅截取首帧。网页不依赖竞品外站图片热链。
- `view.js` 与 `styles.css` 为原知识库新增促销视图，不替换原有图库、需求建议或产品页。
- `Furniwell_Black_Friday_2026_Research_and_Briefs.md` 是可下载的研究和制作交付稿。

## 下次制作广告图时

1. 先读取所选Furniwell商品与具体变体原图，以及其尺寸、桌板拼接方式、桌腿和控制器。产品与事实仍以当时官方页面为准。
2. 在 `briefs` 中选方向，再读其 `refs` 对应素材。借鉴信息层级、购买理由、配色或场景逻辑；至少改变实际空间、机位、人物任务或信息组织，制作原创素材。
3. 只把有 `image` 的记录作为已经看过的视觉参考。文字证据不提供未见的色彩和构图；邮件组件不是完整广告，不能把案例数当投放次数。
4. `待核／复用` 记录不代表某年最终活动。页面年份、发送日期、图内期限和文件名要分开判断。2026尚未发生的11月投放不可补造。
5. 正式排版前填入真实活动价、优惠参照、适用SKU、门槛、代码、叠加规则、期限和德国时间。当前HW15与桌椅42欧入口未被本研究确认为黑五方案。
6. 普通Economy白色120×60保持四拼板、白色两节倒装立柱、T脚及原右侧前沿单控制器；Solid一体板款独立处理；桌架图需明确仅桌架。L型及椅子均锁定各自官方结构。
7. 同时交付各比例无字底图与适用的促销排版图。PMax依据官方现行图片规范；Feed主图单独保留干净商品图。不得改标竞品原图发布，不复制竞品奖项、评价、联名IP或服务承诺。
8. 购买回收与订单结果决定去留。CTR仅用于诊断；PMax自然分配和素材评级不能当作随机A/B结果。

## 更新要求

新增案例必须保留 `source_url`、市场、时间证据、素材角色及图片取得状态。新增图片先检查尺寸和可见内容，排除跟踪像素；不通过生成式工具补造竞品广告。每次更新重新统计记录、品牌和图片数量，并核对JSON与JS一致。

研究参考图版权归原品牌及权利人。用于Furniwell正式广告的素材需由自有或获授权素材重新制作。
